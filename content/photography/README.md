# Photography Content

Add your photos to this folder. Each image should have an accompanying `.json` file with the same name.

## Example

For a photo named `sunset-beach.jpg`, create `sunset-beach.json`:

```json
{
  "description": "Golden hour at the beach, capturing the last light of day.",
  "category": "landscape",
  "date": "2024-10-15"
}
```

## Categories

Common categories: landscape, portrait, street, architecture, nature, travel

## Supported Formats

- JPG/JPEG
- PNG
- WebP
